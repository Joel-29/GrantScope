# CROPS

Module 1 supports the project's principles through a local, MIT-licensed foundation. It does not satisfy the end-to-end hackathon criteria.

| Principle             | Foundation                                                                               | Later evidence needed                                                                       |
| --------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Censorship resistance | No central application backend                                                           | Operational anonymous route and documented recovery                                         |
| Open source           | MIT license, source, tooling, setup; [repository](https://github.com/Joel-29/GrantScope) | Reproducible deployment and public submission access                                        |
| Privacy               | No analytics, RPC, indexer, remote fonts, or persisted wallet data                       | Verified worker reads, accurate route ledger and exclusions                                 |
| Security              | Strict types, accessible UI, no signing code, foundation tests                           | Correct allowance reads, authorization guards, simulation and fresh revocation verification |
