# Demo

Module 2 can demonstrate the interface only. It is not the prize demo and cannot sign transactions or contact Ethereum.

## Current shell walkthrough

Start `npm run dev`. Open the overview, enter the workspace, and inspect the unavailable dashboard measurements. Open Permissions and its truthful unimplemented state. Visit Privacy Lab to confirm the transport is not initialized. On mobile, open/close navigation with keyboard or touch. Read Methodology for the documented boundaries.

In Settings, switch between dark/light/system themes and open the data-policy dialog. Open the transaction activity drawer to see its real empty state. In development only, visit `/design-system` to inspect clearly labeled fictional rows, mobile cards, and manually selected loading/error states. Those fixtures are not a chain demo and are excluded from the production build.

## Planned three-minute real demo

1. Initialize a verified anonymizing worker and show a real Sepolia block number and eth_call.
2. Inspect a controlled Sepolia account and an actual approval on a deployed test ERC-20.
3. Explain the current allowance and bounded discovery coverage.
4. Connect the controlling wallet, review and simulate approve(spender, 0), and request wallet confirmation.
5. Wait for confirmation, independently re-read the allowance anonymously, and show zero only after verification.
6. Inspect the actual route ledger, bootstrap exclusions, and wallet submission count.

Before running this future demo: independently verify endpoint/worker compatibility; fund a test-only wallet; deploy or verify the test token; record real deployment and approval transactions. No wallet, token address, test transaction, or Permit2 testnet deployment is supplied by Module 1. Never place keys or seed phrases in the repository or frontend environment.

If transport fails, show the failure, retry, or select another independently verified anonymous route. Do not claim a direct route is anonymous. Until operational evidence exists, leave the demo marked incomplete.
